Planned TypeScript package `@corvin-chess/design-system` for design tokens, UI components, motion hooks, and board/piece rendering used by [web](https://github.com/corvin-chess/web) and other Corvin clients. Visual assets come from [assets](https://github.com/corvin-chess/assets). No package scaffold, tokens, or board renderer is in this repository yet. Piece sets and board art stay Corvin-original; no third-party piece sets.
